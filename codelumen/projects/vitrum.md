# Vitrum — Astro Site

Vitrum is the **public website bootstrap** — the starting point for institutional and marketing sites.

## Stack

- **Astro** + **TypeScript**
- **Tailwind CSS**
- Static-first, SEO-ready, lightweight

## When to reach for it

Use Vitrum when the deliverable is a content/marketing site rather than an app: landing pages, institutional sites, documentation fronts. For an authenticated web app, start from [app.vigil](/projects/app.vigil) instead.

## Conventions

Vitrum doesn't have its own dedicated rule set yet — it follows the [Shared Conventions](/rules/shared/conventions) (git, commits, PRs, code hygiene). When Astro-specific rules are added under `.claude/rules/`, they'll appear here automatically.
